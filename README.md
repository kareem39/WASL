# WASL — Starter v0.1

واجهة أولية عربية RTL لمشروع توصيل محلي في العريش.

## الملفات
- index.html: الهيكل والواجهة.
- styles.css: التصميم والألوان والاستجابة للموبايل.
- app.js: فلترة الأقسام والبحث التجريبي.

## التشغيل
افتح index.html من خلال استضافة صفحات ثابتة أو محرر ويب يدعم HTML/CSS/JS.
هذه نسخة واجهة فقط؛ لا يوجد تسجيل حقيقي أو قاعدة بيانات أو طلبات أو دفع إلكتروني بعد.

## هوية التصميم
- أسود: #111111
- برتقالي: #ff6b1a
- أبيض: #ffffff

## ملاحظات
- بيانات المحلات تجريبية وليست محلات حقيقية.
- البريد hello@wasl.example عنوان توضيحي فقط ويجب استبداله.
- لا تجمع بيانات عملاء حقيقية في هذه النسخة.
